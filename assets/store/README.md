# Storefront illustration

- `card-shop.webp`: created for Bán Card Thui using the built-in ImageGen tool on 2026-10-24, then encoded to WebP. No cropping or repainting. Used only as decorative shop artwork, never as a photo of inventory.
- Store background: reuses `../hoenn/coast.webp` from the inventory UI, with a cream overlay and reduced saturation. The hero, catalog, purchase guide, lookup and footer use opaque cream panels so the scenery never sits behind reading text.
- `collectors-motif.svg`: earlier, unused edge-motif experiment retained as an asset; the live storefront now uses the Hoenn scene.

## ImageGen prompt

Use case: stylized-concept. Asset type: a wide decorative hero illustration for the real Pokémon trading-card storefront 'Bán Card Thui', used inside a small rectangular game dialogue window, around 500x220 CSS pixels; will also crop to a narrow portrait on phones. Create a charming Pokémon trading card shop interior in authentic Pokémon Ruby/Sapphire Game Boy Advance pixel art: crisp, deliberate low-resolution square pixels, limited warm cream, wood brown, sage green, sapphire navy and muted ruby red palette, no gradients or painterly detail. Straight-on slightly elevated top-down GBA view. A friendly Pikachu shopkeeper behind a small wooden counter in the CENTER, showing an open card binder to a Mudkip customer in front of the counter. Make their trading-card exchange immediately legible at small size. One neat glass card display with three collectible cards, one closed binder and a few organized booster packs. Small Poké Ball emblem as the shop decor. Cream walls and pale wood floor with ample quiet empty space around the central scene. Cozy, orderly, collector shop atmosphere. Wide landscape 3:2 composition, all important content grouped in the middle 50% of the image so it can crop to mobile, scene fills image edge to edge. No outdoor beach, no landscape, no gold coins, no treasure chests, no piles of clutter, no UI, no buttons, no readable text or letters, no watermark. Flat game sprite art with consistent pixel grid; no 3D render, no faux retro blur.
